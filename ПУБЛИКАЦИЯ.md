# Публикация на GitHub Pages

**Сайт:** https://esmarch.github.io/avtoservis/
**Репозиторий:** https://github.com/Esmarch/avtoservis

Уже сделано: репозиторий создан, файлы отправлены, Pages включён (ветка `main`, корень).
Git на этом компьютере подключён к GitHub через GitHub CLI (`gh auth login`), поэтому `git push` работает без пароля.

## Как обновлять сайт
В терминале VS Code в папке `avtoservis`:
```bash
git add .
git commit -m "Что поменял"
git push
```
Pages обновится сам через 1–2 минуты. Если изменений не видно — обновите страницу с Ctrl+F5 (браузер держит старую версию в кэше).

## Проверить после публикации
- Открыть с телефона, посчитать в калькуляторе, нажать «Записаться с этой ценой» и пройти запись до конца — должно появиться «Готово!»
- Выбрать «Замену масла» — должен остаться только бокс 3
- Оставить заявку «Перезвоните мне»
- Фото открываются по клику, карта показывается
- F12 → Console — без красных ошибок
- Превью: отправить ссылку себе в «Избранное» в Telegram — должна появиться картинка
- Если подключили Telegram (НАСТРОЙКА-ФОРМЫ.md) — обе заявки приходят в чат

## Как опубликовать следующий проект так же
1. Один раз на компьютере: `gh auth login --web` (уже сделано).
2. В папке проекта:
```bash
git init -b main
git add .
git commit -m "Первая версия"
gh repo create ИМЯ-ПРОЕКТА --public --source . --push
gh api -X POST repos/Esmarch/ИМЯ-ПРОЕКТА/pages -f "source[branch]=main" -f "source[path]=/"
```
3. Через 1–2 минуты сайт будет на `https://esmarch.github.io/ИМЯ-ПРОЕКТА/`.

## Отозвать доступ GitHub CLI
github.com → Settings → Applications → Authorized OAuth Apps → GitHub CLI → Revoke.
