# ШинаПро — лендинг шиномонтажа и автосервиса с калькулятором и онлайн-записью

Демо-проект для портфолио. Автосервис и контакты вымышленные, фото — бесплатные с Unsplash ([источники](img/ИСТОЧНИКИ-ФОТО.md)).

**Сайт:** https://esmarch.github.io/avtoservis/

## Что внутри
- Светлый дизайн «чистый сервис»: белый, графит, оранжевый акцент, «дорожная» полоса под заголовками
- Таблица цен шиномонтажа по радиусам + карточки услуг (прокол, хранение, ТО, диагностика, масло)
- **Калькулятор шиномонтажа:** радиус × тип авто × работы, итог сразу
  - кнопка «Записаться с этой ценой» выбирает услугу в записи и передаёт расчёт в комментарий
- **Онлайн-запись:** услуга → бокс → дата → свободное время → имя, телефон, авто
  - боксы фильтруются по типу работ: шиномонтаж — боксы 1–2, ремонт и ТО — бокс 3
  - «любой свободный» — сайт сам подбирает бокс, окна считаются по длительности услуги
- Форма «Перезвоните мне»
- Заявки уходят в Telegram владельцу (маска телефона, проверка полей, защита от спама)
- Почему мы, фото сервиса с увеличением, отзывы с рейтингом, вопросы-ответы, контакты и Яндекс.Карта

## Технологии
HTML, CSS, JavaScript без фреймворков. Mobile-first, адаптив под телефон, планшет и ПК.
SEO: title, description, Open Graph, микроразметка `AutoRepair`, favicon, alt у картинок.
Фото в WebP, превью галереи 20–45 КБ, большие версии грузятся только по клику.
Заявки уходят в Telegram через Google Apps Script — токен бота не попадает в код сайта ([настройка](НАСТРОЙКА-ФОРМЫ.md)).

Цены калькулятора — объект `CALC`, расписание — объект `BOOKING` в начале `script.js`; услуги и боксы — в разметке.
